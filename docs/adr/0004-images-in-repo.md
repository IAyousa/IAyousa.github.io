# 配图随仓库存放，不依赖外部图床

文章配图统一放仓库 `source/images/`，随 git 历史版本化，不引入 PicGo/对象存储等外部图床依赖。

**Considered Options**：外部图床（仓库永远轻，但多一个会挂的依赖，图床一挂全站裂图）。

**Consequences**：仓库体积随图片增长（个人博客量级可控）。日后若迁图床，策略是新文章用图床、旧图原地不动，把裂图范围限制在切换日之后——本决策的"半不可逆"性质即在于此。

**登记例外**（2026-09-11，dev-log 09）：`source/favicon.ico` 是站点根路径副本——`/favicon.ico` 是跨平台的老惯例路径，浏览器/爬虫会直接探这个地址，平台约定优先于目录统一。其余图标资产仍在 `source/images/`。
