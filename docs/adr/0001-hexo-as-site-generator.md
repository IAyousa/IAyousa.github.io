# 选 Hexo 作为站点生成器

博客以"记录"为第一目标、作者后续想学习魔改框架，而 Hexo 的中文教程与主题生态（搜索命中率）是所有候选里最高的，本机已有 Node 环境即装即用。

**Considered Options**：Hugo（单文件极速，但中文生态小、本机未装）、Astro/VitePress（更现代但前端心智负担高）、Jekyll（GitHub 原生免 CI 配置，但 Windows 上 Ruby 环境体验差）。

**Consequences**：换生成器等于全站迁移（文章 front-matter、主题、插件全重来），这是一个季度级别的 lock-in，故记录在案。
